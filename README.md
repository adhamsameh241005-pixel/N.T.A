# NTA — موقع إكسسوارات الخرز

كل الملفات (الكود + الصور) في نفس المجلد، عشان الرفع يبقى أسهل ومفيهوش مشاكل مسارات.

## خطوات الرفع الصحيحة على GitHub

1. روحي على الريبو بتاعك على GitHub (اللي عملتيه قبل كده أو ريبو جديد).
2. لو فيه ملفات قديمة (زي مجلد `images` أو نسخة قديمة من index.html) امسحيها الأول عشان منتلخبطش.
3. دوسي **Add file → Upload files**.
4. من جهاز الكمبيوتر، افتحي المجلد ده (`nta-site-flat`)، واختاري **كل الملفات مع بعض** (index.html + style.css + script.js + كل صور product-01.jpg لحد product-14.jpg) — اختاريهم كلهم دفعة واحدة (Ctrl+A) واسحبيهم مرة واحدة لمنطقة الرفع.
5. تأكدي إن العدد اللي اترفع = 16 ملف بالظبط (لو ناقص ملف يبقى مرفعش صح، كرري الرفع).
6. دوسي **Commit changes**.
7. من **Settings → Pages** تأكدي إن الـ Source = **Deploy from a branch**, Branch = **main**, Folder = **/ (root)**.
8. افتحي اللينك بتاع الموقع تاني بعد دقيقة أو اتنين (ودوسي Ctrl+Shift+R في المتصفح عشان تتأكدي إن المتصفح مش لسه محتفظ بنسخة قديمة/كاش).

## لو الصور لسه مش ظاهرة
- افتحي الريبو على GitHub وشوفي هل فايلات الصور (product-01.jpg... إلخ) موجودة فعلاً في نفس صفحة index.html ولا لأ.
- افتحي صورة واحدة من جوه GitHub وشوفي اسمها بالظبط طابق حرف بحرف (حروف كبيرة/صغيرة بتفرق في GitHub Pages).
